# Fieldwork principles

## The habitat is not the inhabitant

Fieldwork supplies memory, roots, tools, interfaces, and durable state. A profile supplies identity,
relationships, expression, and preference. Installing the software must not install a personality.

## Roots are ordered inputs, not hidden defaults

A profile declares every root and its placement. System roots establish durable orientation. Tail
roots accompany the current user turn and remain later than ordinary assembled context. The loader
records exactly which bytes were used.

## Memory is not imagination with good formatting

Conversation archives, retrieved passages, authored memories, observations, hypotheses, and current
instructions are different kinds of evidence. Fieldwork preserves those distinctions and their
provenance instead of flattening fluent text into biography.

## The agent must be able to author its own durable state

An agent home is not solely an operator-maintained prompt. The agent can write and revise memories,
preferences, projects, and expression through explicit, inspectable mechanisms. Durable changes are
attributed, conflict-checked, and reversible.

## Context is a measured resource

Every context source has an explicit placement and budget. Truncation is visible in receipts. A
later source cannot silently disappear because an earlier extension filled an unbounded prompt.

## Capabilities are affirmative

Packs are selected by configuration, validated before setup, and shut down with the host. Merely
placing executable files on disk does not activate them.

## Customization changes presentation, not identity

Appearance and expression are shared, validated stores that both operator and agent may use. They do
not rewrite roots, message content, or remembered claims as a side effect.

## Failure leaves an honest remainder

Optional context may be omitted with a diagnostic. Metadata stripping must fail closed. Persistence
must either verify as committed or stop at the ambiguous edge; it must never silently guess past a partial
write. A failed decoration or attachment must not destroy an otherwise valid reply.
