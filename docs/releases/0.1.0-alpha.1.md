# Fieldwork 0.1.0-alpha.1

This is Fieldwork's first public prerelease: a local-first browser habitat for persistent,
profile-driven agents. It is an alpha intended for people who are comfortable inspecting a local
Node.js application, keeping their own backups, and reporting sharp edges.

## Highlights

- A local authenticated browser room with saved, renameable, archiveable conversations, exact
  raw-history recovery, and an expandable account of which roots, memories, room notes, and tools
  were offered to each reply.
- User-authored identity, relationship, and voice roots; Fieldwork supplies mechanisms rather than
  prescribing a persona.
- Multiple separately housed agents with supervised switching, moving, recovery copies, reset,
  portable export, and portable import.
- An explicitly optional Fieldwork Expert help agent with closed, read-only access to the
  documentation shipped in the build; it cites sections and does not treat manuals as live-state evidence.
- Append-only, lifecycle-aware memory with provenance, corrections, expiry, reminders,
  obligations, verdicts, and inspectable retrieval receipts. Automatic recall matches words, with
  an optional loopback-only meaning match for paraphrases.
- Per-agent model-service, model, and reasoning-effort choices, plus contextual tool groups that
  may stay resident, load only when requested, or remain unavailable.
- Reversible appearance, mood, portrait, guide, shelf, collection, and notebook state with visible
  ownership and history.
- Optional check-ins, task heartbeats, outside readers, goals, promises, Telegram, and Discord,
  all default-off and bounded by explicit configuration.
- Accessibility controls for typeface, text scale, spacing, density, layout, motion, and optional
  decorative surfaces.

## Install

Fieldwork requires Node.js 22 or newer. After verifying the attached `SHA256SUMS.txt`, extract the
source archive and run `Start Fieldwork.cmd` on Windows. On other supported systems, open a terminal
in the extracted directory and run:

```sh
npm ci --no-fund --no-audit --ignore-scripts
npm start
```

The separately attached npm-shaped `.tgz` is a bounded installable artifact for inspection and
advanced workflows. It is not published to the npm registry, and the package retains its
`"private": true` guard.

## Important boundaries

- Agent state and credentials are stored locally, but configured model requests and bridge traffic
  go to the services the operator selects.
- Telegram and Discord delivery receipts distinguish refusal, rejection, partial acceptance, and
  uncertainty; they cannot manufacture destination-supported exactly-once delivery.
- The optional web reader is off by default and accepts only validated public HTTP(S) destinations.
- Host add-ons and provider behavior are outside Fieldwork's local JavaScript boundary. Read
  [the tagged limitations](https://github.com/4thkira/fieldworkharness/blob/v0.1.0-alpha.1/docs/limitations.md)
  before relying on a guarantee.
- This alpha has no compatibility promise for every future state-file revision. Keep backups and
  inspect recovery copies before removing them.

Security problems should be reported through the private route in the
[tagged security policy](https://github.com/4thkira/fieldworkharness/blob/v0.1.0-alpha.1/SECURITY.md),
not through a public issue. Participation is governed by the
[tagged code of conduct](https://github.com/4thkira/fieldworkharness/blob/v0.1.0-alpha.1/CODE_OF_CONDUCT.md).
